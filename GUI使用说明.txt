Scryfall 卡图下载器 GUI 使用说明

1. 将 scryfall_cards_gui.pyw 和 启动GUI.cmd 放在同一文件夹。
2. 双击 启动GUI.cmd。已配置 Python 文件关联时，也可直接双击 scryfall_cards_gui.pyw。
3. 在左侧粘贴牌表，或点击“导入 TXT / YDK”。每行一种牌，例如：
   4 Lightning Bolt
   4 Counterspell
   8 Forest
   1 碎骨巨人
   每行只写中文或英文中的一种名称，不要将中英文用斜杠并列。
4. 在右侧选择纸张、语言顺序，并勾选需要的选项。网络请求自动处理，无需设置并发。
5. 点击“开始下载”，在下方查看查询、下载、降并发和 PDF 排版日志。

完整选项
- PDF 纸张：A4 竖向，每页 9 张；A3 横向，每页 18 张。
- 万智牌语言优先顺序：默认简体、繁体、英文；支持预设及自填语言代码。
- 卡牌游戏：万智牌、宝可梦TCG（中文）、宝可梦TCG（英文）、游戏王；运行中不可切换。
- 宝可梦中文固定繁体 zh-tw，英文固定 en，各用自己的系列代码和卡号，不跨语言回退。游戏王固定简中→日文→英文，百鸽全部失败后YGOPRODeck英文回退；不能自填语言顺序。
- 查询／下载并发：万智牌与游戏王 4／8，两种宝可梦 64／64，随游戏选择自动切换。
- TCGdex 没有公开的硬性请求限额，也没有公布查询或图片并发上限；PTCG 64／64 为本机实测择优预设，不是官方上限。2026-10-13 固定样本对比16／32／64，查询64最快；同样128张高清PNG、120秒socket超时分别耗时83.469／81.328／68.703秒，全部成功，因此下载也选64。若低档达到最高吞吐的95%，优先低档。
- 这些是当前链路短时结果，不保证长期容量；较短的25秒图片超时在64并发时出现过4次读取超时，图片应沿用120秒设置。详细数据见 tcgdex-benchmark-results/report.md；官方说明 https://tcgdex.dev/faq#are-there-rate-limits 。
- 宝可梦已接入 TCGdex：牌表必须“数量 卡名 系列代码 编号”，例如 1 Shaymin DRI 10、2 Froslass PR-SV 117；中文使用自身代码，例如 1 傑尼龜 SV2a 007。缺少系列或编号的数字行导致整个任务拒绝运行。
- 万智牌与宝可梦均跳过非数字开头行（分类标题/Total Cards），有效行必须数量开头。
- 系列卡号精确匹配后再取真实卡 ID，10 可匹配010；不按同名重印替换。无图分别报告缺图，SVE23已知有资料但图片未收录。
- 自动处理网络请求，受限时等待并重试。
- 生成 PDF：关闭后只下载图片及生成清单。
- 裁切框：生成 PDF 时可选择显示或隐藏。
- 仅查询选图：优先使用所选游戏图片索引，生成清单，不下载图片、不生成 PDF；游戏王新密码用HEAD探测来源候选。
- 重新选图并下载（忽略图片缓存）：重新选择版本并下载；语言顺序用于新牌名或重新选图，普通任务直接复用已缓存版本。
- 停止任务：终止当前任务，已完成图片和索引保留在当前游戏图片目录；万智牌/宝可梦先保存候选地址，游戏王每张图片完成后保存索引，未完成卡片下次重新选择。每次开始仍创建新的任务记录目录。

输出
图片按游戏隔离，固定放在 GUI 程序旁边；切游戏时目录标签同步：
  卡图输出\mtg-pics\                    万智牌已下载图片
  卡图输出\mtg-pics\index.json          牌名、中英文别名、版本及图片地址索引
  卡图输出\ptcg-pics\zh-tw\         宝可梦繁体卡图与 ptcg-index.json
  卡图输出\ptcg-pics\en\            宝可梦英文卡图与 ptcg-index.json
  卡图输出\yugioh-pics\               游戏王卡图与独立索引
旧 pics 已弃用，不自动读取、迁移或从历史清单回流，也不导入另一游戏目录。
每次点击开始，PDF、牌表、清单和日志仍按本地启动时间创建独立任务目录：
  卡图输出\yymmdd-hhmmss\cards.pdf    本次生成的 PDF（启用时）
  卡图输出\yymmdd-hhmmss\manifest.txt  下载结果清单
  卡图输出\yymmdd-hhmmss\manifest.json 详细记录
  卡图输出\yymmdd-hhmmss\本次牌表.txt  本次提交的牌表
  卡图输出\yymmdd-hhmmss\运行日志.txt  本次运行日志
例如 2026 年 10 月 12 日 10:10:30 开始的任务，保存到 卡图输出\261012-101030\。
同一秒内启动多个任务时，会自动添加 _01、_02 等序号，保证不覆盖已有任务。
下载任务和仅查询任务都会创建各自的记录目录；图片缓存跨任务永久复用，不按 24 小时过期。
已有时间戳任务的 cards 图片会自动迁入 mtg-pics，并更新 JSON 清单路径；相同内容去重，同名不同版本保留独立文件。原有 PDF 保留。
“打开输出文件夹”和“打开 PDF”指向当前或最近一次任务；“打开当前游戏卡图”按选择打开 mtg-pics、ptcg-pics/zh-tw、ptcg-pics/en 或 yugioh-pics。
“打开 PDF”仅在本次任务生成新的卡册后启用。

下载策略
先检查 mtg-pics 索引；已记录的主图继续复用。旧记录若尚未检查 token，将按保存的打印 ID 或可靠 Scryfall 图片 URL 补查一次；成功的无关联结果也保存。无可靠 ID 的自制图会标注无法自动检查，不猜关系。
新牌名才查询主卡选图；关联 token 按具体 ID 查询，主卡与 token 使用统一图片下载调度，默认 8 线程；查询独立保持 4 线程。完整且已检查的缓存无需 API 或图片请求；失败的检查下次允许重试。
缺失或校验损坏的图片按已保存的 URL 补下载，双面牌只补缺失面；PNG 校验分块 CRC，避免把残缺传输当成完整缓存。
Scryfall 当前对 /cards/named 和 /cards/search 的上限是每秒 2 次（500ms）；旧版 0.11 秒间隔不适合这些接口。
新版所有查询线程共用至少 0.6 秒的 API 请求间隔。收到 429 后间隔自动加长，冷却至少 30 秒，并按重复受限次数延长。
完整遵守 Retry-After 的秒数或 HTTP 日期，不再将服务器等待时间截断到 60 秒。
图片默认无固定启动间隔，包括普通网络错误的重试；线程数限制、服务端冷却与 Retry-After 仍生效。可用命令行 --image-interval 0.2 启用保守间隔。
图片受限后暂停新请求、延长间隔，并将默认下载并发按 8→4→2→1 减半；已有请求可继续完成。
重复牌名只查询一次，相同打印版本查询共享结果。
新牌名的 API 查询结果仍缓存 24 小时，保存在程序旁边的 .scryfall-api-cache；不缓存 403、429、5xx 或无效响应。已有图片和牌名索引保存在 mtg-pics，不受这个过期时间影响。
2026-10-12 本机代理实测：零固定图片启动间隔，4/8/16/32 并发各取 48 张不同图，全部成功，无 403/429/503；各档耗时 48.77/41.32/56.38/48.81 秒。8 并发吞吐最高，因此默认采用 8；8 和 32 档各一次 SSL EOF，重试后成功。小样不证明服务端上限，不保证长期吞吐或不被阻塞。
查询 HTTP 403 表示访问被拒绝：停止本次后续 API 请求并报告原因，不当作普通限流反复重试。
查询持续 429 或先后 4 次进入限流后，会停止后续网络查询；图片先后 4 次进入限流或持续被阻断也停止后续图片请求。
同一程序目录中一次只允许一个任务执行，避免多窗口叠加请求频率；其他窗口会显示等待当前任务结束的提示。
数量仅影响 PDF 排版，同一任务内同一图片只下载一份，PDF 按牌表顺序放置。
官方说明：https://scryfall.com/docs/api/rate-limits

自动关联 token / 徽记
- 合并解析卡与实际打印的 all_parts，仅获取 component=token 的关联对象，不递归反向关联。
- 按可靠 oracle ID 保持身份并选择语言打印；缺少 oracle ID 使用具体打印。同名不同规格不合并，不按名称推测图片。
- 每种身份只下载一份，在主卡之后默认追加一份至 PDF；双面 token 按牌面顺序获取所有有效面。不根据主卡数量推算生成数量。
- 清单分别记录主卡 cards/summary、tokens/token_summary，以及主卡到 token 的关系、实际语种和徽记类型。
- 规则可能创建 token 但没有可下载关联对象时明确提示；查询失败或下载失败保留主卡成果，整体显示部分失败，下次可重试。
- token 缺失或损坏时按保存 URL 补下载；完整缓存不再查询或下载。重新选图同时刷新关联信息。
- 仅查询模式记录选图与关系，不下载、不生成 PDF。

宝可梦下载策略
- 仅向所选语言TCGdex查询，独立API缓存24小时；404/限流/无效响应不缓存为成功，失败下次重试。
- 英文支持DRI/TWM/ASC等官方短代码和PR-SV兼容别名；中文使用中文卡库set ID。卡名、卡号及系列详情不一致时报告失败，不按名称改选。
- 按精确语言/系列/编号缓存，完整图片零查询复用；缺失或损坏使用已存URL补下载。任务开始下载前保存图片地址，停止任务后可恢复。
- 下载high.png，数量仅影响PDF，相同图片只下载一次。保持牌表顺序、按数量排版；部分失败保留成功卡图/PDF与完整失败清单，不进行MTG token查询。
- 仅查询不下载/PDF；强制刷新所指定版本。当前TCGdex系列无图时不猜地址或切换其他卡。

游戏王 YDK 牌表与下载策略
- 选择无后缀“游戏王”，导入 .ydk 或粘贴YDK文本。每行仅一个1–8位ASCII数字正整数卡片密码（允许省略前导零），不是“数量 卡名”；重复密码会累计数量，跨主卡组、额外卡组和副卡组仍累计。
- 空行、#created by、#main、#extra、!side、名称行、带数量或其他文字的行均跳过；全角数字和其他非ASCII数字也跳过。没有有效密码则不启动任务。
- 示例（89631139共3张，另有3种密码各1张，合计4种牌、6张）：
  #created by YGOPRO
  #main
  89631139
  89631139
  46986414
  #extra
  23995346
  !side
  83764718
  89631139
- 固定简中→日文→英文：先尝试百鸽的对应语言卡图，百鸽全部失败后才使用YGOPRODeck英文卡图回退。
- 图片缓存独立保存到卡图输出/yugioh-pics，不与万智牌或宝可梦混用；数量影响PDF排版，同一密码的图片只下载一份。
- 百鸽WebP及回退JPEG经Pillow完整解码转为RGB PNG，保存为密码.png，无语种文件名后缀。坏图继续回退，失败与仅查询探测不进入成功图片缓存。
- 百鸽与YGOPRODeck按来源独立限速和冷却；API启动间隔0.1秒，图片至少0.15秒（保守客户端设置，不是站方上限）。403/429停止该来源，不阻断另一来源。游戏王实际并发取查询和下载配置较小值。
- 仅查询对候选图发HEAD请求，不下载图片和生成PDF；完整缓存零网络请求。损坏图片优先按保存URL修复，失败重新执行回退链；强制刷新从百鸽简中重选。

高级命令行
  --game mtg / ptcg-zh / ptcg-en / ygo：默认 mtg；宝可梦中文/英文不回退；游戏王使用固定语言回退顺序。
  --pics 目录：默认随游戏使用mtg-pics、ptcg-pics/zh-tw、ptcg-pics/en或yugioh-pics；不自动删除此目录。
  --workers：万智牌默认4（1–16）；宝可梦默认64（1–64）。
  --download-workers：万智牌默认8（1–32）；宝可梦默认64（1–64）。
  --image-interval 秒数：默认 0，可显式设置 0.1 或 0.2；拒绝负数、NaN、无穷大。
  MTG/PTCG的0仅取消固定图片启动间隔，不取消线程限制、Retry-After或服务端冷却；MTG API间隔独立为0.6秒。游戏王图片仍保持至少0.15秒，API为0.1秒。
  示例：python scryfall_cards_threaded.py deck.txt --image-interval 0.1

运行环境
Python 3（建议 3.10 或更新版本），包含 Tkinter/Tcl/Tk。
源码运行请先执行 python -m pip install -r requirements.txt 安装支持WebP的Pillow；dist/CardDownloader.exe已随包包含Pillow和Tcl/Tk，无须安装Python。按游戏需要能访问 Scryfall、TCGdex，或百鸽与YGOPRODeck及其图片服务。
启动入口会依次尝试 py、python，以及本机 DSH 已提供的 Python。

手动打开图形界面：
  python scryfall_cards_gui.pyw

打印时选择“实际大小 / 100%”，卡牌尺寸为 63×88 mm。
