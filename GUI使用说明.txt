Scryfall 卡图下载器 GUI 使用说明

1. 将 scryfall_cards_gui.pyw 和 启动GUI.cmd 放在同一文件夹。
2. 双击 启动GUI.cmd。已配置 Python 文件关联时，也可直接双击 scryfall_cards_gui.pyw。
3. 在左侧粘贴牌表，或点击“导入 TXT”。每行一种牌，例如：
   4 Lightning Bolt
   4 Counterspell
   8 Forest
   1 碎骨巨人
   每行只写中文或英文中的一种名称，不要将中英文用斜杠并列。
4. 在右侧选择纸张、语言顺序和线程数，并勾选需要的选项。
5. 点击“开始下载”，在下方查看查询、下载、降并发和 PDF 排版日志。

完整选项
- PDF 纸张：A4 竖向，每页 9 张；A3 横向，每页 18 张。
- 语言优先顺序：默认简体、繁体、英文；支持预设及自填语言代码。
- 线程数（查询 / 下载共用）：默认 4，可填写 1 到 16，无需单独设置查询线程数；不稳定的网络可先用 2。
- 生成 PDF：关闭后只下载图片及生成清单。
- 裁切框：生成 PDF 时可选择显示或隐藏。
- 仅查询选图：优先使用图片索引，新牌名才访问 Scryfall；生成清单，不下载图片、不生成 PDF。
- 重新选图并下载（忽略图片缓存）：重新选择版本并下载；语言顺序用于新牌名或重新选图，普通任务直接复用已缓存版本。
- 停止任务：终止当前任务，已下载图片保留在共享 pics；选图索引先行保存，未完成图片下次按已有地址补下载。每次开始仍创建新的任务记录目录。

输出
图片由所有任务共用，固定放在 GUI 程序旁边：
  卡图输出\pics\                    所有已下载图片
  卡图输出\pics\index.json          牌名、中英文别名、版本及图片地址索引
每次点击开始，PDF、牌表、清单和日志仍按本地启动时间创建独立任务目录：
  卡图输出\yymmdd-hhmmss\cards.pdf    本次生成的 PDF（启用时）
  卡图输出\yymmdd-hhmmss\manifest.txt  下载结果清单
  卡图输出\yymmdd-hhmmss\manifest.json 详细记录
  卡图输出\yymmdd-hhmmss\本次牌表.txt  本次提交的牌表
  卡图输出\yymmdd-hhmmss\运行日志.txt  本次运行日志
例如 2026 年 10 月 12 日 10:10:30 开始的任务，保存到 卡图输出\261012-101030\。
同一秒内启动多个任务时，会自动添加 _01、_02 等序号，保证不覆盖已有任务。
下载任务和仅查询任务都会创建各自的记录目录；图片缓存跨任务永久复用，不按 24 小时过期。
已有时间戳任务的 cards 图片会自动迁入 pics，并更新 JSON 清单路径；相同内容去重，同名不同版本保留独立文件。原有 PDF 保留。
“打开输出文件夹”和“打开 PDF”指向当前或最近一次任务；“打开共享卡图（pics）”直接打开所有图片。
“打开 PDF”仅在本次任务生成新的卡册后启用。

下载策略
先检查 pics 索引；已记录的牌名、英文名或中文名直接取图，不进入 API 查询，也不重新下载完整图片。
只有新牌名才查询选图，再将图片并行下载到 pics；两个阶段共用界面中的线程数，默认 4。
缺失或校验损坏的图片按已保存的 URL 补下载，双面牌只补缺失面；PNG 校验分块 CRC，避免把残缺传输当成完整缓存。
Scryfall 当前对 /cards/named 和 /cards/search 的上限是每秒 2 次（500ms）；旧版 0.11 秒间隔不适合这些接口。
新版所有查询线程共用至少 0.6 秒的 API 请求间隔。收到 429 后间隔自动加长，冷却至少 30 秒，并按重复受限次数延长。
完整遵守 Retry-After 的秒数或 HTTP 日期，不再将服务器等待时间截断到 60 秒。
图片请求统一按至少 0.2 秒启动间隔发送，包括普通网络错误的重试。*.scryfall.io 没有官方速率上限，0.2 秒是本程序的保守值。
图片受限后暂停新请求、延长间隔，并将并发按 4→2→1 减半；已有请求可继续完成。
重复牌名只查询一次，相同打印版本查询共享结果。
新牌名的 API 查询结果仍缓存 24 小时，保存在程序旁边的 .scryfall-api-cache；不缓存 403、429、5xx 或无效响应。已有图片和牌名索引保存在 pics，不受这个过期时间影响。
近期小规模真实下载测试观察到 4/8 个同时进行的图片响应体，16 个请求均为 HTTP 200，没有 403/429/503；11 个响应体读取不完整（IncompleteRead）。这是传输中断，具体原因未确定；未据此提高默认并发。
查询 HTTP 403 表示访问被拒绝：停止本次后续 API 请求并报告原因，不当作普通限流反复重试。
查询持续 429 或先后 4 次进入限流后，会停止后续网络查询；图片先后 4 次进入限流或持续被阻断也停止后续图片请求。
同一程序目录中一次只允许一个任务执行，避免多窗口叠加请求频率；其他窗口会显示等待当前任务结束的提示。
数量仅影响 PDF 排版，同一任务内同一图片只下载一份，PDF 按牌表顺序放置。
官方说明：https://scryfall.com/docs/api/rate-limits

运行环境
Python 3（建议 3.10 或更新版本），包含 Tkinter/Tcl/Tk。
不需要 pip 安装第三方库；下载需要能访问 Scryfall。
启动入口会依次尝试 py、python，以及本机 DSH 已提供的 Python。

手动打开图形界面：
  python scryfall_cards_gui.pyw

打印时选择“实际大小 / 100%”，卡牌尺寸为 63×88 mm。
